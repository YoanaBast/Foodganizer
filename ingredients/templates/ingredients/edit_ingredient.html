How the conversion to Base works

1 — Each ingredient has a default measurement unit with its base quantity.
The default unit + base quantity are used to set the nutrients table (kcal, etc).

2 — When converting to other measurement units, the base quantity is reduced to 1.
The calculations then answer the question "How much of the new unit is in 1 base unit?"

Formula: X [new unit] = 1 [base units]

Example Base (always 1) New unit Conversion Why?
Milk 1 ml cup 240 Because 1 cup = 240 ml
Flour 1 g tbsp 8 Because 1 tbsp of flour ≈ 8 g
Egg 1 pc gr 0.0166 Because 1 egg ≈ 60g

3 — While the Conversion to Base can be edited manually, you can use the Add Additional Measurement Units for convenience.
It is easy to use - just say how much of the new unit equals base quantity of the default unit.

≈ Is used for some items, as their quantity is not exact. For example an egg could be between 50 and 70g.
