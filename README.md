The Foodganizer is a food database that offers very customizable CRUD on very detailed items. It's a recipe book + calorie tracker and is built around one idea: you're in control. Every recipe, ingredient, unit, category, and tag is yours to create and customize. 

Want to add 1 shoe-full of milk to your recipe? Go for it!

#### Meal Suggestions - fill your digital fridge and get meal suggestions that won't send you to the store! 

#### Grocery List - Or if you feel like going out, geenrate a grocery list fast and easy from recipes of your choice! 

#### BMI calculator, calorie tracker, and much more! Everything in one place.

If you hate the cognitive load that comes with planning meals every single day - this app is for you! 



On a more serious note, this was developed as an uni assignment. 

I've used Django Monolith + REST, Cloudflare, Redis, Supabase, Sentry, Brevo, Cloudinary, NginX, GUnicorn, Custom Server (Spaceship) and deployed it containerized in Docker on a AWS EC2 Ubuntu machine. Full Stack + Deployment. 
Currently the AWS deployment is down, because it is a personal project and I'm out of credits. Redeployed on Render and switched the nginx for whitenoise. 

I also plan to revisit the CSS, as I am now much more familiar with CSS and see a huge room for improvement.
